🛠️ Setup Instructions

Follow these simple steps before running the script:

1️⃣ Add Your ChatGPT API Key

Replace the placeholder with your actual OpenAI API key.

2️⃣ Replace the Logo URL

Update this line with your own logo image URL:

logo_url = "YOUR_LOGO_URL"

3️⃣ Use Correct Font Files

Make sure the font paths exist.
Use your own font files for both English and Hindi text:

font_en = "/path/to/english-font.ttf"
font_hi = "/path/to/hindi-font.ttf"


(If the font doesn’t load → you will get OSError: cannot open resource)

4️⃣ Add Your Video

Update:

video_path = "/content/YOUR_VIDEO.mp4"


Use your own video file uploaded to Colab or local environment.
